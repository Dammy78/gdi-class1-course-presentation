How an instructor delivers this course

This summary follows the canonical instructor peer-review narrative (RC2-CHG-063). For segment-level detail, use the facilitation script PDF.

Course purpose

Structured teaching for Class 1 learner licence holders building hazard perception, lawful habits, and sound decisions—not only manoeuvre practice. Supervised practice with a licensed supervisor continues after the course.

Architecture at a glance

ComponentHours
MOD-01 – MOD-06 facilitated classroom16.0
Summative theory (supervised, closed-book)2.0
MOD-07 practical (continuous on-road)2.5
Total contact20.5

Delivery flow

Facilitators progress module by module with formative checks and workbook alignment, integrate learning in MOD-06, gate with summative theory, then run MOD-07 as one continuous practical session. Question banks, keys, and scoring rubrics remain in the controlled evidence library only.

Practical competencies

PC-01–PC-12 are assessed in MOD-07 using provider criteria in the submission. Plain-language competency descriptions appear in the instructor source narrative; detailed rubrics are withheld from web copy by design.
